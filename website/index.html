◆ Terminal coding agent

The harness is the lever.

Veyyon is a terminal coding agent that edits real code. It's tuned to work well with open and hosted models alike, so you can pick the model that fits the task instead of paying for the most expensive one by default.

Edits

Edits that apply cleanly

Edits are anchored to file content, not line numbers, and checked before they apply — so fewer of them land malformed.

Models

You pick the models

Set the model you talk to, the one that runs subagents, and the one that compacts context. Each is set on its own.

Control

Clear about what it does

Sandbox and approval settings you control. It tells you what it did, what it skipped, and what it couldn't do.

Model selection

Three explicit models. No default magic.

Most agents bury model choice in an opaque per-role maze. Veyyon gives you three plain choices — and keeps roles in settings, scoped per profile, for when you actually want them. See how models work →

  • Interactive model — the model you talk to, chosen live with /model.
  • Subagent model — one setting for the model your subagents run on.
  • Compaction model — one setting for the model that compacts context.
  • Roles in settings — kept, scoped per profile, out of the picker. default is not a model.
# ~/.veyyon/config.yml
model: anthropic/claude-sonnet-5
subagent:
  model: anthropic/claude-haiku-4-5
compaction:
  threshold: 80
  type: handoff       # or snap
  model: openai/gpt-5

✓ each slot uses its own model
In the box

What's included.

TypeScript and Bun run the agent loop and TUI. Rust handles the parts that need to be fast — grep, PTY, and hashline edits. See all features →

Plan mode & goals

Ground, propose, then execute — tools gated to non-mutating work until you approve the plan.

Sandbox & approvals

Read-only, workspace-write, or full access. Per-tool approval tiers you control, fail-closed by default.

Memory

Durable project memory across sessions — recall on the way in, retain on the way out. Off until you turn it on.

Session branching

Fork, clone, and label conversation threads. Explore a path without losing the trunk.

Cockpit

Live multi-agent view — a model per subagent, drill into any one, watch the work as it happens.

MCP, skills, hooks

Extend with MCP servers, authored skills, and lifecycle hooks. Plus browser, web search, and headless exec.

The thesis

The model is the engine. The harness is the lever.

Prompt order, tool exposure, edit format, and repair all change how much a model gets done. Veyyon tunes those to each model, so a cheaper one can hold its own on real work.

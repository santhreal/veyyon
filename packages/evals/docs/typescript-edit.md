# TypeScript-edit suite

An offline edit benchmark: 80 tasks generated by mutating real TypeScript sources, executed by the
in-process backend, graded by a compile and a diff. No container, no network, and — apart from the
model calls a run makes — no external service.

Suite: `src/suites/typescript-edit/suite.ts`. Backend: `in-process`.

## What a task is

A task is one mutated file plus the instruction to restore it. Generation takes a source file from
the fixtures corpus, applies one registered mutation, and records the original bytes as the expected
result. A trial passes when the model's edit produces a file that formats and compiles to the
original.

`src/suites/typescript-edit/generate.ts` builds tasks; `src/suites/typescript-edit/tasks.ts` loads
them from disk; `src/suites/typescript-edit/verify.ts` grades a trial;
`src/suites/typescript-edit/formatter.ts` normalizes bytes with Prettier before comparison, so a
whitespace difference is not scored as a failed edit.

## Mutations

`src/suites/typescript-edit/mutations/registry.ts` is the one owner of the mutation set. Twenty
mutations are registered from ten family modules:

| Family | Module | Examples |
|---|---|---|
| operator | `mutations/operator.ts` | comparison, equality, logical, negation, inc/dec, arithmetic |
| literal | `mutations/literal.ts` | boolean flip, off-by-one |
| access | `mutations/access.ts` | optional-chain removal |
| call | `mutations/call.ts` | argument swap |
| regex | `mutations/regex.ts` | quantifier swap |
| unicode | `mutations/unicode.ts` | hyphen homoglyph |
| identifier | `mutations/identifier.ts` | multi-edit rename |
| duplicate | `mutations/duplicate.ts` | duplicated line with a flipped literal |
| structural | `mutations/structural.ts` | adjacent-line swap, if/else swap, early-return removal, statement deletion |
| import | `mutations/import.ts` | named-import swap |

Each mutation declares `isMultiEdit`, `isStructural` and `allowsMultipleHunks`. Prompt generation and
hunk counting read those declarations; nothing matches on a mutation's name.
`registerMutation` rejects a duplicate id with `DuplicateMutationError`, and `requireMutation`
rejects an unknown id with `MutationNotFoundError`.

## Corpus and provenance

The corpus is the archive `datasets/typescript-edit/fixtures.tar.gz`.
`src/suites/typescript-edit/extract.ts` is the one extractor: it reads the archive, hashes it, and
extracts into `.cache/`. A missing or unreadable archive fails closed; a caller that wants the soft
answer passes `allowMissingArchive: true` and receives `{ ok: false }` explicitly.

`src/suites/typescript-edit/provenance.ts` reports `{ suite, version, sha }` for a run. The sha is
the archive digest, so two runs claiming the same corpus can be compared, and a run whose corpus
could not be read reports `sha: null` rather than a digest of nothing.

`src/suites/typescript-edit/mutations` plus the archive digest make generation reproducible: the same
archive and the same seed produce the same 80 tasks.

## Prompts

Every prompt is a `.md` file imported with `{ type: "text" }` and rendered with Handlebars — none is
built by string concatenation in code.

- `src/suites/typescript-edit/prompts/generate-task-{easy,medium,hard,nightmare}.md` — the task
  instruction at four difficulty tiers.
- `src/suites/typescript-edit/prompts/repro-{new-feature,barrel-reexport}.md` — content-reproduction
  tasks used by the Argot bench.
- `src/suites/typescript-edit/prompts/argot-{forced-adoption,sigil-emission}.md` — the Argot probes.
- `src/suites/typescript-edit/adapter/prompts/benchmark-{system,task,retry}.md` — the system, task and
  retry prompts the runner sends.

## Running it

```sh
bun packages/evals/src/suites/typescript-edit/adapter/cli.ts --help
```

`--model` and `--output` are required. `--max-tasks`, `--task-concurrency` and `--runs` take an
integer >= 1 and refuse anything else, so a typo cannot reach the scheduler as NaN runs per task or
as a run with no workers. `--tasks` takes task ids and names the ones the corpus does not hold.
`--fixtures-archive` measures a regenerated archive instead of the bundled one. `--list` prints the
task ids and names as JSON. Every refusal happens before the archive is unpacked, prints the usage
text, and exits 2; a run that failed exits 1.

`src/suites/typescript-edit/adapter/runner/scheduler.ts` drives the trials across workers,
`adapter/runner/session.ts` runs one task against the harness, and `adapter/report.ts` renders the
result table.

## Argot bench

`src/suites/typescript-edit/argot-bench.ts` runs the edit tasks twice, with shorthand encoding off
and on, and reports the token delta. `src/suites/typescript-edit/argot-certify.ts` is the safety
arm: it asserts parity of the produced edits and zero handle leakage. Both are opt-in through
`ARGOT_BENCH_MODEL`; without it the live certification tests skip rather than silently pass.

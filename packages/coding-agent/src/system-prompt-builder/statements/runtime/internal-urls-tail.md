- `mcp://<uri>`: MCP resource
- `issue://<N>` (or `issue://<owner>/<repo>/<N>`): GitHub issue, disk-cached. Bare lists recent issues.
- `pr://<N>` (or `pr://<owner>/<repo>/<N>`): GitHub PR, same cache. Bare lists recent PRs.
- `veyyon://`: harness docs; AVOID unless the user asks about the harness itself.
